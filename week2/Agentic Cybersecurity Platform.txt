Agentic Cybersecurity Platform
Milestone 2 – Agent Integration with Security Tools

Project Overview

During the previous milestone, we successfully established the intelligence layer of the platform:

* MITRE ATT&CK Knowledge Base
* Vector Database
* RAG Architecture
* Red Team Agent
* Detection Agent
* ATT&CK Retrieval System

The agents are now capable of understanding attack techniques and reasoning over cybersecurity knowledge. However, they still operate in isolation from real cybersecurity environments and tools.


Why Agentic AI?

Traditional security tools generate findings, alerts, logs, and telemetry. They are excellent at collecting information but limited when it comes to reasoning and decision-making.
AI agents excel at:

* Planning
* Correlation
* Prioritization
* Campaign reasoning
* Threat prediction

The goal is :
AI Agents decide.
Security Tools execute.

Agent Framework Selection

Several agentic frameworks were evaluated.

CrewAI

Recommended for multi-agent collaboration.
Strengths:

* Role-based agents
* Hierarchical workflows
* Easy orchestration
* Suitable for Red Team and Threat Intelligence operations

Example:
Recon Agent → Attack Planner Agent → Reporting Agent
or
Collection Agent → Correlation Agent → Prediction Agent
CrewAI is recommended as the primary framework for the project.

SmolAgents

Recommended for lightweight autonomous agents.
Strengths:

* Simple implementation
* Fast experimentation
* Strong tool-calling capabilities
* Good for Proof-of-Concept development

Ideal for:

* IOC enrichment agents
* ATT&CK retrieval agents
* Small autonomous tasks


LangGraph

Recommended for complex agent workflows.
Strengths:

* Stateful execution
* Human-in-the-loop support
* Long-running workflows
* Multi-step reasoning

Ideal for:

* Campaign generation
* Threat correlation
* Attack path planning


AutoGen

Recommended for collaborative AI teams.
Strengths:

* Agent-to-agent communication
* Debate and reasoning mechanisms
* Task delegation

Ideal for:

* Red Team vs Threat Intelligence simulations
* Adversarial agent interactions
* Purple Team exercises


AI Red Team Platform

The Red Team platform aims to emulate realistic adversary behavior against the MedFlow healthcare infrastructure.
Rather than executing isolated security tests, the platform generates complete attack campaigns.

Core AI Agents

Campaign Orchestrator Agent
Responsible for defining attack objectives.
Example:
Goal:
Access Patient Records
The agent creates a complete attack plan and coordinates other agents.
Reconnaissance Agent
Uses:

* Nmap
* BloodHound
* LDAP Enumeration
* DNS Enumeration

Responsibilities:

* Discover assets
* Identify attack surfaces
* Classify infrastructure

Infrastructure knowledge graph.

Healthcare-specific attack opportunities.

Shared Intelligence Layer

Both platforms will share common services:

* MITRE ATT&CK
* Sigma Rules
* Vector Database
* Neo4j Knowledge Graph
* Agent Framework
* Shared Memory Layer

This ensures offensive and defensive agents reason using the same intelligence foundation.

Knowledge Graph Integration

Neo4j will serve as the central intelligence hub.
The graph will contain:

* Assets
* Users
* Active Directory Objects
* Threat Actors
* Campaigns
* ATT&CK Techniques
* Detections
* Blockchain Entities

This allows agents to reason over relationships rather than isolated events.

Expected Outcome

The final platform will not be a collection of disconnected security tools.
Instead, it will become an Agentic Cybersecurity Ecosystem where AI agents coordinate offensive and defensive operations, leverage traditional security frameworks, build attack campaigns, correlate intelligence, and provide predictive insights for healthcare cybersecurity environments.
